Backoffice is the merchant and product management console for authoring configurable product catalogs, defining compatibility rules, mapping commerce variants, and controlling publishing lifecycles.

## Core tasks

| Task | Description |
| --- | --- |
| **[Managing products](/backoffice/products)** | Create products, set unique keys, configure catalog status, and manage drafts |
| **[Choices and values](/backoffice/choices-and-values)** | Add configuration dimensions, options, sort orders, required flags, and defaults |
| **[Constraints](/backoffice/constraints-and-rules)** | Author incompatible value sets and understand validity and availability |
| **[Commerce mappings](/backoffice/commerce-mappings)** | Link valid configuration combinations to external SKUs and variant IDs |
| **[Managing revisions](/backoffice/revisions)** | Manage editable drafts, the active published revision, and archived history |
| **[Publishing](/backoffice/publishing)** | Review current dependency checks, freeze a snapshot, publish and activate, and recover safely |
| **[Shopify import](/backoffice/shopify-import)** | Connect Shopify stores, preview options and variants, and import catalog products |
| **[Troubleshooting](/backoffice/troubleshooting)** | Diagnose authoring issues, disabled options, missing mappings, and publish blockers |

## Product workspace tabs

When viewing a product in Backoffice, the workspace is organized into tabs:

- **Product**: Top-level details, product key, description, and status.
- **Options**: Manage Choices, ChoiceValues, defaults, and ordering.
- **Variants**: Inspect the generated combinatorial matrix, validity states, and SKU mappings.
- **3D**: Assign base 3D models, linked assets, and open the 3D Studio.
- **Commerce**: Configure commerce providers, identity choices, and variant GID mappings.
- **Rules**: Create incompatibility constraints. Configuration-rule records are legacy/migration-only.
- **Activity**: Review audit logs and version history across revisions.
