CubeCom Pro connects product merchandising, real-time 3D visualization, configuration resolution, and commerce checkout into a unified pipeline.

## Overview

Traditional configurators fragment product knowledge across 3D rendering engines, rule plugins, spreadsheet matrices, and e-commerce platforms. CubeCom Pro unifies these capabilities on top of a single versioned configuration graph:

| Surface | Purpose | Primary users |
| --- | --- | --- |
| **[Backoffice](/backoffice)** | Author catalog products, define choices, enforce compatibility rules, map variant SKUs, and manage revisions | Merchandisers, Product Managers, Operations |
| **[3D Editor](/editor)** | Inspect an attached model and edit supported material and visibility bindings in a canvas-first workspace | 3D Artists, Technical Directors |
| **[Storefront runtime](/customizer)** | API-first contract for resolving selections into validity, availability, visual state, and commerce state | Storefront Engineers, Experience Designers |
| **[Developers / API](/developers)** | Programmatic access via GraphQL and REST to author catalog graphs, resolve configurations, and orchestrate headless checkout | Frontend & Backend Engineers |
