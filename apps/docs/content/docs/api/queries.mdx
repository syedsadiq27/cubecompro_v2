## `resolveConfiguration`
Resolves a shopper selection against a product configuration graph.

- **Signature**: `resolveConfiguration(input: ConfigurationStateInput!): ResolvedConfigurationModel!`
- **Arguments**:
  - `input`: [`ConfigurationStateInput!`](/api/inputs#configurationstateinput)
- **Returns**: [`ResolvedConfigurationModel!`](/api/objects#resolvedconfigurationmodel)

### Example
```graphql
query Resolve($input: ConfigurationStateInput!) {
  resolveConfiguration(input: $input) {
    valid
    violations
    availabilityJson
    threeD {
      rootObjectAssetRevisionId
      activeObjectAssetRevisionIds
    }
    commerce {
      sku
      variantReference
    }
  }
}
```

## `product`

## `productRevisionDetail`

## `shopifyCatalogProducts`
