## Product content versioning

- Product configuration is versioned through [product revisions](/concepts/product-revision). Each revision is an immutable snapshot after publishing.
- Asset history is versioned through [ObjectAssetRevision](/concepts/assets). Published revisions pin specific asset revisions.

## API schema versioning

- GraphQL and OpenAPI schemas evolve independently of product content versions.
- Schema changes are documented in the [Changelog](/resources/changelog).
